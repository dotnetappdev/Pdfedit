PdfEdit for Mac

PdfEdit as a Mac app, for Apple silicon and Intel Macs. Open the disk image and drag PdfEdit to Applications.

Finding the latest files...

First time on a Mac? If macOS says it can't check the app, right-click PdfEdit in Applications and choose Open.

PdfEdit for Linux

PdfEdit as a Linux app for 64-bit PCs. The AppImage is one file: make it executable (right-click > Properties > Allow running as a program, or chmod +x) and open it.

Finding the latest files...

Blank window? PdfEdit shows its pages with WebKitGTK, which most desktops already have. If yours hasn't: sudo apt install libwebkit2gtk-4.1-0 (Ubuntu, Debian, Mint) or sudo dnf install webkit2gtk4.1 (Fedora).

PdfEdit for the web

Run PdfEdit on your own server and use it from any browser, on your team's laptops, phones and tablets. It needs the .NET 10 runtime.

git clone https://github.com/dotnetappdev/pdfedit.git
cd pdfedit
dotnet run --project PdfEdit.Blazor

Then open the address it shows. Hosting guide

Which one?

  • On Windows: PdfEdit for Windows has every tool, including scanners.
  • On a Mac: PdfEdit for Mac. Apple silicon for M1 and newer Macs, Intel for older ones (Apple menu > About This Mac).
  • On Linux: the AppImage runs on most distributions; the tarball is the same app in a folder.
  • For a team: host the web version once; everyone uses it in their browser.

System requirements

  • Windows 10 (version 2004) or 11, 64-bit
  • macOS 12 Monterey or later
  • Linux, 64-bit, with WebKitGTK 4.1 or 4.0 (Ubuntu 22.04, Debian 12, Fedora 38 or later)
