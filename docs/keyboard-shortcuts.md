# Keyboard shortcuts

[← Back to README](../README.md)

Press F1 in the app to see this list. Single-letter shortcuts are ignored while you're typing in a field or text box.

## Files and pages

| Action | Keys |
|--------|------|
| Open / Save / Save As | Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| Close / Print | Ctrl+W / Ctrl+P |
| Next / previous page | Ctrl+Right / Ctrl+Left |
| Zoom in / out / fit | Ctrl+Plus / Ctrl+Minus / Ctrl+0 |
| Rotate page | Ctrl+] / Ctrl+[ |
| Search everything | Ctrl+Shift+F |
| Export / import comments (XFDF) | Ctrl+Shift+E / Ctrl+Shift+I |

## Editing

| Action | Keys |
|--------|------|
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Copy / paste / duplicate | Ctrl+C / Ctrl+V / Ctrl+D |
| Select all | Ctrl+A |
| Delete | Del |
| Nudge | Arrow keys (Shift for bigger steps) |
| Resize | Ctrl+Arrow (Ctrl+Shift for bigger steps) |
